# Supply Chain Data Analytics

## Project Overview

This project focuses on analyzing supply chain data to understand business performance, identify trends, and generate meaningful insights. It involves data cleaning, data validation, data analysis, and visualization using different tools.

## Business Objectives

- Analyze supply chain operations and performance.
- Clean and validate datasets to improve data quality.
- Identify important trends and patterns in supply chain data.
- Analyze key business metrics.
- Create an interactive Power BI dashboard for better decision-making.

## Tools and Technologies

- **Microsoft Excel:** Data cleaning and preprocessing.
- **MySQL:** Data validation, cleaning, and SQL-based analysis.
- **Python:** Data analysis using Pandas, NumPy, and Matplotlib.
- **Power BI:** Interactive dashboard development.
- **Google Colab:** Python notebook environment.

## Project Workflow

### 1. Data Cleaning Using Excel

- Imported and organized supply chain datasets.
- Checked for missing values and duplicate records.
- Formatted columns and prepared datasets for analysis.

### 2. Data Validation and Analysis Using MySQL

- Imported CSV datasets into MySQL.
- Performed data validation and cleaning.
- Used SQL queries to analyze supply chain data.
- Generated insights using filtering, grouping, and aggregate functions.

### 3. Data Analysis Using Python

- Used Pandas for data manipulation and analysis.
- Used NumPy for numerical operations.
- Used Matplotlib to create charts and visualizations.
- Explored patterns and trends in the datasets.

### 4. Dashboard Development Using Power BI

- Connected the datasets to Power BI.
- Created interactive charts and visualizations.
- Developed a dashboard to monitor supply chain performance.
- Presented key metrics and business insights.
